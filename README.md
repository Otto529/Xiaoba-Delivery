# <img src="./public/xiaoba.jpeg" width="40" height="40" style="vertical-align: middle; border-radius: 50%;"> 小八外卖 (Xiaoba Delivery)

一个基于 **React** + **Tailwind CSS** 构建的轻量级全流程外卖演示系统。无需后台数据库，直接打开即用，数据自动保存到浏览器。

[English ](./docs/README_EN.md) | [繁體中文](./docs/README_TW.md)

---

## 🌟 项目亮点

- **全流程模拟**：涵盖了从商家上架商品、用户下单支付、到骑手接单配送的所有环节。
- **三端合一**：一个网页包含用户端、商家端、骑手端，支持无缝角色切换。
- **零配置启动**：使用 `localStorage` 模拟数据库，关闭页面或刷新，你的数据依然还在！
- **极速体验**：响应式设计，完美适配手机和电脑，界面清新（蓝色主题）。

---

## 🚀 快速上手

### 1. 安装 Node.js
请优先安装 [Node.js](https://nodejs.org/zh-cn) (建议使用 LTS 版本)。

### 2. 安装依赖
```bash
npm install
```

### 3. 启动项目
```bash
npm run dev
```
打开浏览器访问 `http://localhost:5173` 即可开始体验。

## 📱 角色说明

### 🙋‍♂️ 用户端 (User)
- **浏览美食**：查看商家上架的各种美食。
- **一键下单**：填写收货地址、联系方式和备注。
- **立即支付**：模拟真实的支付流程。
- **订单追踪**：实时查看订单状态（待支付、备餐中、配送中、已完成）。
- **评价功能**：用餐结束后可以发表、修改或删除评价。

### � 商家端 (Merchant)
- **商品管理**：支持上传本地图片、修改价格、调整库存、上下架商品。
- **订单处理**：接收新订单，点击“备餐完成”通知骑手。
- **评价管理**：查看客户对商品和店铺的反馈。

### 🛵 骑手端 (Rider)
- **接单中心**：查看已备餐完成的任务。
- **配送导航**：显示详细的收货人信息、电话和地址。
- **送达确认**：一键点击确认送达。

## 🛠️ 技术栈

- **前端框架**：React 18
- **样式处理**：Tailwind CSS (响应式布局)
- **图标库**：Lucide React
- **数据持久化**：Browser LocalStorage
- **构建工具**：Vite

## ❓ 常见问题

**Q: 为什么没有链接数据库？**
A: 为了方便在 GitHub 上展示和让别人直接上手，本项目采用了 `localStorage` 技术。这意味着你不需要安装 MySQL 或 MongoDB 就能拥有数据保存功能，非常适合作为作品展示或原型演示。

**Q: 怎么切换角色？**
A: 页面顶部有【用户】【商家】【骑手】的切换按钮，点击即可瞬间切换视角。
