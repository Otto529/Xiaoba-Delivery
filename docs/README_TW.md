# <img src="../public/xiaoba.jpeg" width="40" height="40" style="vertical-align: middle; border-radius: 50%;"> 小八外賣 (Xiaoba Delivery)

一個基於 **React** + **Tailwind CSS** 構建的輕量級全流程外賣演示系統。無需後台數據庫，直接打開即用，數據自動保存到瀏覽器。

[简体中文](../README.md) | [English](./README_EN.md)

---

## 🌟 項目亮點

- **全流程模擬**：涵蓋了從商家上架商品、用戶下單支付、到騎手接單配送的所有環節。
- **三端合一**：一個網頁包含用戶端、商家端、騎手端，支持無縫角色切換。
- **零配置啟動**：使用 `localStorage` 模擬數據庫，關閉頁面或刷新，你的數據依然還在！
- **極速體驗**：響應式設計，完美適配手機和電腦，界面清新（藍色主題）。

## 🚀 快速上手

### 1. 安裝 Node.js
請優先安裝 [Node.js](https://nodejs.org/zh-cn) (建議使用 LTS 版本)。

### 2. 安裝依賴
```bash
npm install
```

### 3. 啟動項目
```bash
npm run dev
```
打開瀏覽器訪問 `http://localhost:5173` 即可開始體驗。

## 📱 角色說明

### 🙋‍♂️ 用戶端 (User)
- **瀏覽美食**：查看商家上架的各種美食。
- **一鍵下單**：填寫收貨地址、聯繫方式和備註。
- **立即支付**：模擬真實的支付流程。
- **訂單追蹤**：實時查看訂單狀態（待支付、備餐中、配送中、已完成）。
- **評價功能**：用餐結束後可以發表、修改或刪除評價。

### 🏪 商家端 (Merchant)
- **商品管理**：支持上傳本地圖片、修改價格、調整庫存、上下架商品。
- **訂單處理**：接收新訂單，點擊「備餐完成」通知騎手。
- **評價管理**：查看客戶對商品和店舖的反饋。

### 🛵 騎手端 (Rider)
- **接單中心**：查看已備餐完成的任务。
- **配送導航**：顯示詳細的收貨人信息、電話和地址。
- **送達確認**：一键點擊確認送達。

- **前端框架**：React 18

- **數據持久化**：Browser LocalStorage

## ❓ 常見問題

**Q: 為什麼沒有鏈接數據庫？**

A: 為了方便在 GitHub 上展示和讓別人直接上手，本項目採用了 `localStorage` 技術。這意味著你不需要安裝 MySQL 或 MongoDB 就能擁有數據保存功能，非常適合作為作品展示或原型演示。

**Q: 怎麼切換角色？**

A: 頁面頂部有【用戶】【商家】【騎手】的切換按鈕，點擊即可瞬間切換視角。
